# BubbleEngine

BubbleEngine is a HTML/CSS/JS python browser built from PyQtWebEngine and it aims as much as possible to be as fast as possible while also having a ***minimal*** ram footprint. May be buggy.

# BubbleEngine V2.0

BubbleEngine V2.0 moves from HTML/CSS/JS to a custom ELE/POS/APPSCRIPT format and is coded in Rust and uses the Vulkan renderer. Currently being coded.
